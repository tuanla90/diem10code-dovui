# Đố Vui Ngày Hội (tên tạm)

Gian đố vui của chuỗi diem10code: an toàn mạng, đồ họa, HTML và CSS. Hai màn hình gần như giống hệt, chọn bản đúng để ăn xu, rồi giữ **So** để hai bản lật qua lại và thấy chỗ khác. Thiết kế nằm ở [DESIGN.md](DESIGN.md).

Trang tĩnh, không cần cài gói, không cần build.

```bash
npm start   # http://localhost:4300/
npm test    # máy kiểm câu đố và luật chung
```

Thêm `?mo-khoa` vào đường dẫn để mở hết gói khi duyệt. Deploy Railway như các repo anh em (`railway.json` có sẵn).

Phông chữ, ảnh Sola và Luna, bảng màu, icon và âm thanh chép từ `diem10code-dohoa`.
